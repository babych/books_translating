# 🐝 Енциклопедія Бджільництва (A. I. Root — ABC and XYZ of Bee Culture)

Перший повний український переклад фундаментальної енциклопедії бджільництва Амоса Айвза Рута та Ернеста Р. Рута.

- 🌐 **Офіційний сайт книги:** [https://babych.github.io/books_translating/](https://babych.github.io/books_translating/)
- 📥 **Пряме завантаження PDF (728 сторінок, 63 МБ):** [Завантажити книгу](https://github.com/babych/books_translating/releases/download/v1.0/Root_Beekeeping_Encyclopedia_UA.pdf)

---
### Про видання
Класичне видання охоплює всі сфери пасічницької справи: анатомію та біологію бджіл, будову сучасних вуликів, селекцію та виведення маток, медозбір, хвороби бджіл та методи їх лікування.
